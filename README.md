# Room Rental Website

A modern responsive room rental website built with React, Tailwind CSS, and Express.

## Features

- Landing page with hero search and CTA
- Room listing and filtering
- Room details page with gallery and booking form
- Nearby attractions and contact section
- Login/signup with simple authentication
- Booking dashboard and confirmation flow

## Setup

### Backend
```powershell
cd backend
npm install
npm start
```

### Frontend
```powershell
cd frontend
npm install
npm run dev
```

## Notes

- The backend uses in-memory storage for demo bookings and auth.
- You can extend it with MongoDB later.
